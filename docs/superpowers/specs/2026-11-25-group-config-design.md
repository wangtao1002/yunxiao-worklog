# 小组配置迁移和成员任务明细

用户已确认：导入导出仅针对小组配置；成员必须携带 ID 和姓名，并写入设置页通讯录。

- 使用版本化 JSON：type、version、orgId、groups（id/name/memberIds）、members（id/name）。只导出小组引用的成员，不包含凭据、字段映射或偏好。
- 同组织导入，完整校验后小组与通讯录同次写入；同 ID 小组更新，新 ID 追加，其他组和联系人保留；同名不同 ID 冲突拒绝。导入前展示数量和合并规则。
- 缺失成员 ID、姓名、引用、重复成员或跨组织配置拒绝，不修改本地数据。
- 排名内点击成员名字原地展开任务，使用当前已筛选快照按负责人 ID 匹配；展示任务、项目、状态、预计和实际工时及云效链接。空数据和不完整结果分别提示。
